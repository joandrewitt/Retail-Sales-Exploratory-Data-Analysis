# Retail-Sales-Exploratory-Data-Analysis
Exploratory Data Analysis (EDA) of a retail sales dataset using Python, Pandas, Matplotlib and Seaborn. This Mission Ready project explores the dataset, identifies sales patterns and trends, and uses visualisations to generate meaningful business insights and support data-driven decisions.

**Project description**

This project focuses on performing Exploratory Data Analysis (EDA) on a retail sales dataset using Python. The analysis was completed as part of the Mission Ready Data Analyst Accelerator programme.

The main objective was to explore the sales dataset, understand the characteristics of the data, identify patterns and trends, and create visualisations to support business insights.

**Tools & Technologies**
- Python
- Pandas
- Matplotlib
- Seaborn
- Microsoft Fabric
- Jupyter Notebook

**Time-Series Forecasting**

- Sales data was aggregated by month to create a chronological time series.

- The data was divided into training and testing periods while maintaining chronological order.

- An ARIMA model was then used to forecast sales for the test period.

- Model predictions were compared with actual sales values and evaluated using Root Mean Squared Error (RMSE).

**Analysis performed**

The project covers areas such as:

- Loading and exploring the dataset
- Understanding the structure and data types
- Checking for missing values
- Data cleaning and preparation
- Descriptive statistics
- Exploring sales-related variables
- Grouping and aggregation
- Identifying patterns and trends
- Data visualisation using Matplotlib and Seaborn
- Drawing business insights from the analysis

**Project workflow**

**Raw Sales Data** → **Data Exploration** → **Data Cleaning** → **Descriptive Analysis** → **EDA** → **Visualisation** → **Business Insights**
